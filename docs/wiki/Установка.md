# Установка

Требования: Python ≥ 3.11, сеть к YouTube. API-ключ **не нужен**.
`ffmpeg` — только для Whisper-fallback.

```bash
# uv (рекомендуется): детерминированное окружение + запуск
git clone https://github.com/FroggerHH/kw-yt-transcript && cd kw-yt-transcript
uv sync
uv run kw-yt --help

# uv как CLI-утилита
uv tool install .

# Альтернативы без uv
pipx install .
pip install -e .

# Whisper-fallback (распознавание речи, если субтитров нет)
pipx install ".[asr]"
```

> PyAV ≥ 15 + faster-whisper 1.2.1 на Python 3.14 (`TypeError metadata_errors`):
> обход встроен — ffmpeg декодирует аудио в сэмплы сам, downgrade PyAV не нужен.

Проверка:

```bash
kw-yt --help
kw-yt --version   # 0.2.0
```

Автодополнение bash (опционально):

```bash
source contrib/kw-yt-completion.bash
```
