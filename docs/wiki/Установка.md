# Установка

Требования: Python ≥ 3.11, сеть к YouTube. API-ключ **не нужен**.
`ffmpeg` — только для Whisper-fallback.

```bash
# pipx (рекомендуется для CLI)
pipx install .

# uv
uv tool install .

# pip, editable для разработки
pip install -e .

# Whisper-fallback (распознавание речи, если субтитров нет)
pipx install ".[asr]"
```

Проверка:

```bash
kw-yt --help
kw-yt --version   # 0.2.0
```

Автодополнение bash (опционально):

```bash
source contrib/kw-yt-completion.bash
```
