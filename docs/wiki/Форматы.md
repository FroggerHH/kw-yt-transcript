# Форматы и отчёты

Папка видео `<slug>_<video_id>/`:

- `meta.json` — метаданные + `origin` (manual/auto/whisper), `transcript_lang`,
  `fetched_at`, `tool_version`, `asr_model`, `stats`, `thumbnail_file`
- `report.html` — отчёт: статистика, главы-ссылки, кликабельные таймкоды `?t=`,
  поиск с подсветкой, обложка (всё встроено, внешних CDN нет)
- `thumbnail.jpg` — обложка (best-effort: не скачалась — её нет, остальное пишется)
- `transcript.srt` — таймкоды `HH:MM:SS,mmm`
- `transcript.vtt` — таймкоды `HH:MM:SS.mmm`
- `transcript.json` — `[{start, duration, text}]`
- `transcript.jsonl` — строки для RAG
- `transcript.csv` — таблица
- `transcript.txt` — читаемый текст с абзацами
- `transcript.md` — заголовок + статистика + главы + абзацы

Корень корпуса: `index.json` (сводка `{_type, playlist_url, entries, failed}`)
+ `index.html` (таблица-галерея с обложками) + `corpus.jsonl/csv` и `summary.json`
(после [[Команды#export|export]]).
