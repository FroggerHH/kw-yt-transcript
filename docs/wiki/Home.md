# kw-yt-transcript — wiki

Консольная утилита: метаданные и полные транскрипты видео YouTube.
Русскоязычный CLI, работает **без API-ключа**.

- [[Установка]] — pipx / uv / pip, Whisper-extra, проверка
- [[Использование]] — single, multi, плейлист, jobs/resume
- [[Команды]] — fetch, search, serve, export, stats, все флаги
- [[Форматы и отчёты]] — 7 форматов, report.html, index.html, обложки
- [[Конфиг и кэш]] — config.toml, TTL-кэш метаданных
- [[Разработка]] — тесты, архитектура, релизы

Исходники: публичный репозиторий `FroggerHH/kw-yt-transcript`, ветка `main`.
Версия: 0.2.0. Тестов: 181, все зелёные.
