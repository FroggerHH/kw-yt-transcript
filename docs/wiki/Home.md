# kw-yt-transcript — wiki

Консольная утилита: метаданные и полные транскрипты видео YouTube.
Русскоязычный CLI, работает **без API-ключа**.
Проект разработан при участии ИИ: текст с origin auto/whisper распознан
машинным слухом — возможны ошибки (маркировка ⚠ в отчётах, см. [[Форматы и отчёты]]).

- [[Установка]] — uv / pipx / pip, Whisper-extra, PyAV-troubleshooting, проверка
- [[Использование]] — single, multi, плейлист, jobs/resume + субкоманды корпуса
- [[Команды]] — fetch, search, serve, export, stats, все флаги
- [[Форматы и отчёты]] — 7 форматов, report.html, index.html, обложки, AI-маркировка
- [[Конфиг и кэш]] — config.toml, TTL-кэш метаданных
- [[Разработка]] — тесты, архитектура, CI, релизы
