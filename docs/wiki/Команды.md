# Команды

## fetch (по умолчанию, без субкоманды)

Скачивание метаданных и транскриптов. Опции: `inputs`, `--from-file`,
`--out/-o` (./out), `--langs` (ru,en), `--format` (srt/vtt/json/txt/md/jsonl/csv/all),
`--no-fallback-whisper`, `--whisper-model` (small), `--jobs/-j 1–16` (4),
`--resume`, `--version`. Дефолты `--out/--langs/--whisper-model/--jobs`
и `--in` (во всех командах) берутся из конфига, если флаг не передан.

## search — поиск по корпусу

```bash
kw-yt search "ключевое слово" --in ./out
kw-yt search never --in ./out --context 30 --limit 5
```

Группы по видео с числом прямых совпадений (`>` — прямое, пробел — контекст).
Exit 0 (нашёл) / 1 (нет).

## serve — просмотр в браузере

```bash
kw-yt serve ./out --port 8000
```

Раздаёт `index.html`/`report.html` на 127.0.0.1, выход — Ctrl+C.

## export — сводный корпус для RAG

```bash
kw-yt export --in ./out
kw-yt export --in ./out --format csv --out ./all.csv --no-summary
```

Один `corpus.jsonl/csv` + `summary.json` (счётчики, `by_origin`, пропуски).
Пустой корпус — exit 1, нет папки — exit 2.

## stats — сводка корпуса

```bash
kw-yt stats --in ./out
kw-yt stats --in ./out --json
```

Таблица или JSON: видео, реплики, слова, минуты, `by_origin`/`by_lang`.
Пустой корпус — exit 1, нет папки — exit 2.
